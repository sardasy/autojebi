## 재발 방지

- 미반영 첨부/추출 결과를 작업 버튼 근처에 노출하고 각각 명시적인 반영 버튼을 제공한다.
- 파일 미등록, 파일만 등록, 본문 미반영, 분석 가능, 동기화 필요 상태를 구분한다.
- 공고 본문 없이 분석하지 못하게 한다. 기존 제안서나 제품 근거의 본문은 공고 원문으로 대체하지 않는다.
- 빈 파일 목록에서는 본문 추출을 비활성화한다. 서버도 Worker 장애 대신 파일 등록/결과 반영 안내를 반환한다.
- 공백뿐인 원문은 서버에서 차단해 유료 호출을 예약하지 않는다.
- 현재 버전의 성공 결과에만 반영 안내를 제공한다. 동일 본문이나 이전 버전은 재반영 안내 대상에서 제외한다.
- 자동 분석·자동 승인·임의 본문 생성은 추가하지 않았다.
