## 프로그램 보완

- 검색 결과에 기관, 공고번호, 한국 시각 마감을 표시하고 기본적으로 마감 전 공고만 표시한다. 미확인 마감은 마감 전으로 간주하지 않는다.
- 검색 재시작과 실패 시 이전 결과를 제거해 과거 결과를 현재 검색 결과로 오인하지 않도록 했다.
- 저장 성공 후 해당 공고 작업대 링크로 전환되는 동작을 검증했다.
- 마감 경과, 잘못된 날짜, 시간대 미확인 시 서버의 제출 준비 완료를 거부한다. 과거 승인 이력은 보존하며 현재 준비 판정은 재계산한다. 검토 다운로드는 허용한다.
- 본문 미확인 또는 원문 전체 대조 미완료 상태에서 다음 행동이 비교·작성으로 건너뛰지 않고 원문 검토로 연결되도록 했다.
- 입력 버전을 확인하고 정확한 인용만 검토 대기로 추가하는 로컬 검증용 준비 도구를 추가했다. 같은 인용을 중복 등록하거나 회사 자격을 승인하지 않는다.

## 실연동 차단

HWP Worker는 설치 등록이 확인됐으나 `/health`에서 `recovery_required=true`다. 이전 한글 작업의 종료 확인과 공식 복구 절차가 필요하다. 복구 표식 삭제, 보안 우회, 자동 재호출, 사용자의 한글 일괄 종료는 하지 않았다.

이번 제안서 HWP 생성 시도 `69a27b7e-4302-42a8-b56f-3985b3a8520a`는 `template_path`로 차단됐다. 허용 폴더에 운영 템플릿 파일이 없다. 실제 원문 양식과 DB 필드 매핑을 일치시킨 템플릿이 필요하다. 입력값 미리보기의 필수 누락 0은 템플릿 존재나 생성 성공을 뜻하지 않는다.

`ANTHROPIC_API_KEY`는 등록되지 않았다. 새 LLM 호출은 하지 않았고 공고 PDF를 직접 읽어 확인 항목을 만들었다. 회사 증빙·제품 근거·기존 작성자료가 확보되지 않아 비교 제안서와 최종 PDF를 완성할 수 없다. 이 조건이 해결되기 전에는 출시·실무 완료를 선언하지 않는다.
