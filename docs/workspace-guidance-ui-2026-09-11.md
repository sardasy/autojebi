# 작업대 다음 행동 중심 UI

## 변경
- 상단 `지금 할 작업`은 현재 입력과 작업 결과에 맞는 버튼 하나를 제공한다. 다운로드 완료 결과가 있으면 재다운로드보다 첨부 반영을 우선한다.
- 동기화, 다운로드, 결과 반영, 본문 추출, 분석, 원문 검토, 비교 작성, 생성물 검토를 구분한다. 분석 실패는 결과 확인으로 연결하며 자동 재시도하지 않는다.
- 작업 실행 중 상단 버튼은 비활성화된다. 수동 버튼 입력 없이 외부 작업이나 유료 분석을 시작하지 않는다.
- 필수조건 점검은 서류 확인 탭으로 이동하고 기본 접힘. 기타 원문 작업, 원문/증빙 파일 관리, 검토 의견/상태 관리도 접을 수 있다.
- 공고 원문이 없는 단계에는 빈 원문 미리보기와 빈 요구사항 편집기를 표시하지 않는다. 수동 등록은 파일 관리에서 제공한다.
- 이전 입력과 이전 실행 기록은 접고, 종류별 최신 현재 입력 작업을 우선 표시한다. 기존 다운로드·검토·복구 기능은 보존한다.
- 첨부 목록은 다운로드 성공 후 미반영 상태를 `다운로드 완료 · 반영 대기`로 구분한다. 본문 확보 또는 검토 완료로 간주하지 않는다.
- 원문 검토 등 이동 버튼은 해당 탭으로 전환하고 내용 영역까지 스크롤·초점을 이동한다.

## 검증
- 프론트 전체 Vitest 175개 통과, 타입 검사 통과.
- workbench-mock E2E 4개 통과, 기존 opt-in 2개 skip.
- 새로운 E2E는 첨부 반영 후 다음 행동이 본문 추출로 바뀌는지, 추가 작업이 자동 실행되지 않는지, 파일 관리 재열기와 키보드 탭 이동을 검증한다.
- 1280x800 및 390x800 스크린샷 확인: 다음 행동 첫 화면 노출, 페이지 가로 넘침 없음.
- 실제 R26BK01722905-000 화면의 다운로드 완료 4개/반영 대기 안내 확인. 실제 공고의 입력 버전 1과 데이터를 변경하지 않았고 HWP/LLM 호출 또는 승인을 실행하지 않았다.
- API/DB/Worker 변경 없음. 백엔드 전체 테스트는 이번 UI 변경에서 재실행하지 않았다.
