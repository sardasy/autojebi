# Excel / ZIP / PDF 추출 검증 기록

## 구현 범위

- XLSX는 읽기 전용으로 시트·셀 주소, 값, 품목·규격·수량·단가 후보를 보존한다. 수식은 실행하지 않는다. 저장된 계산값이 없으면 미확인으로 남기며 0으로 바꾸지 않는다.
- ZIP은 디스크에 풀지 않고 내부 파일명·해시·크기·처리 결과를 남긴다. 내부 XLSX/PDF만 본문을 읽는다. HWP/HWPX, 도면, 중첩 ZIP 등은 미지원 목록에 보존한다.
- PDF는 페이지별 본문 확보 상태를 기록한다. 빈 페이지 또는 이미지 중심 페이지는 로컬 Tesseract OCR 경로를 사용한다. OCR 결과는 신뢰도와 관계없이 사람 검토가 필요하다.
- API 작업 결과와 원문에 extraction 메타데이터를 보존하며, 일부 내용만 읽힌 파일은 원문 전체 확보나 검토 완료로 자동 판단하지 않는다.
- 원문 파일 해시 검증을 유지한다. PDF 캐시는 페이지 완전성 메타데이터가 있는 정상 결과만 재사용한다.
- 문서 화면에서 셀·품목 수, 미지원 ZIP 구성원, 미확인 페이지와 OCR 상태를 확인할 수 있다.

## 안전 제한

- ZIP 입력/누적 확장 50MB, 500개 항목, 압축률 500배 제한. 경로 탈출, 절대 경로, 심볼릭 링크, 암호화, 중복 이름을 거부한다.
- XLSX XML은 defusedxml로 DTD/엔티티를 거부한다. 시트 행 10,000, 열 200, 총 방문 셀 100,000 제한.
- PDF는 100페이지, OCR는 전체 추출 작업당 최대 10페이지·각 20초. 추출 본문은 200,000자 제한.
- OCR는 고정 인자와 shell=False로 실행하며 원문을 외부 OCR 서비스로 전송하지 않는다. 새 유료 LLM 호출은 없다.

## 검증 결과

- 전체 백엔드: 1,347 passed / 13 skipped (105.89초). tmp/e2e-followup-pytest.xml에 JUnit 결과를 남겼다.
- 프론트: 31개 파일 / 189 passed. 타입 검사 통과.
- 변경 추출 모듈, 라우터, 관련 테스트 Ruff 통과.
- 셀 출처·수식 미확인·부분 ZIP·위험 ZIP·UTF-16 DTD·페이지 누락·OCR 실행 인자·공유 OCR 예산·API 반영 회귀를 포함한다.
- 일부 React 비동기 테스트 act 경고와 Qdrant 클라이언트/서버 버전 경고가 남아 있다.

## 미완료와 적용 상태

- 현재 PATH에서 Tesseract를 찾지 못했다. 실제 스캔 문서 OCR·한국어 언어팩 검증은 미완료이며 mock 검증과 구분한다.
- 구형 XLS, 도면 해석, ZIP 내부 HWP/HWPX 본문 추출은 미지원이다.
- 개발 Python에 defusedxml을 설치하고 pyproject 의존성을 추가했다. 실행 중 API/작업 실행기/HWP Worker는 이번 추출 변경으로 재시작하지 않았다. 최신 코드의 단위 테스트 통과를 현재 서버의 실파일 추출 통과로 해석하지 않는다.
- 원문 내용·페이지 배치 및 실제 공고의 완전성은 담당자 확인이 필요하다. 참고자료와 증빙의 기존 승인 경계는 유지한다.
