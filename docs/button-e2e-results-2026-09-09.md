## 테스트 보정 이력

첫 실행은 검색 갱신 전에 같은 제목의 과거 예시 공고를 열어 실패했다. 기존 자료 수정 전 중단됐으며 `E2E-SAMPLES-1788908821973` 보고서를 보존했다.
`sample-document-loop.spec.ts`는 새 공고번호의 정확한 링크와 URL을 기다리도록 수정했다. HWP는 입력 미리보기만으로 활성화를 기대하던 구형 기대값을 필드 검사/최신 필수조건 기준으로 변경했다. 차단을 실제 HWP 생성 성공으로 세지 않는다.
`WorkspaceClient.test.tsx`의 지원하지 않는 `exact` 옵션을 제거하고 실제 `초안 승인` 이름을 검증하도록 고쳤다.
브라우저 프로세스 실행 제한(EPERM)은 승인된 실행 환경으로 재시도했다. 보안 정책이나 HWP 보호 기능은 변경하지 않았다.

실제 HWP 생성·재열기·배치 검토, 외부 LLM 분석, 실제 증빙 기반 최종 준비 확인, 나라장터 제출은 이번 통과 범위에 포함되지 않는다.
