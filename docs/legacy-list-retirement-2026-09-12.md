# 기존 공고 목록 화면 제거

사용자 요청으로 기존 공고 목록 화면을 제거했다.

- `/notices`의 목록·점수·추천 SKU 화면 코드를 제거했다. 검토 작업대가 활성화된 환경에서는 `/workspace`로 이동한다.
- 작업대가 비활성화된 환경에는 종료 안내만 표시한다. 운영 전환 검증을 통과한 것으로 간주하거나 기능 플래그를 자동 활성화하지 않는다.
- 메뉴에서 기존 공고 작업대 링크를 제거했다.
- 기존 Docker 프론트엔드는 `legacy-ui` 프로필로 기본 실행에서 제외하고 자동 재시작을 해제했다. 과거 이미지의 목록 화면이 계속 노출되지 않도록 실행 중인 `autojebi-frontend`도 정지한다.
- 공고 데이터, 첨부 파일, 작성 서류, 기존 API와 데이터베이스는 삭제하지 않는다.

현재 작업대 실행은 `infra/start-workspace.ps1`과 별도 검증 데이터베이스를 사용한다. Docker 호환 UI를 별도로 검증해야 한다면 최신 코드로 빌드하고 `--profile legacy-ui`를 명시한다. 이는 운영 전환 승인을 의미하지 않는다.
