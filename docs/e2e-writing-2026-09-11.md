## 보완 우선순위

1. **HWP 저장값 불일치 진단**: `api/hwp_worker/com_driver.py`의 저장 후 필드 재조회 비교에서 실패. 어느 물리 필드의 어떤 차이인지 아직 확정하지 못했다. 입력/작업용 템플릿/실패 파일을 대조하고, 검증을 완화하거나 실패 파일을 승인하지 않는다.
2. **누락 검사 동선 연결**: 작성 대상은 확인됐어도 요구사항 0개이면 검사가 즉시 차단된다. 미등록 자체를 누락 검사 결과로 안내하거나, 필요한 등록 단계로 직접 연결하는 개선이 필요하다. 근거 없는 요구사항 자동 승인은 금지한다.
3. **HWP 생성 활성화 안내**: 필드 검사와 입력값 확인 후에도 접힌 필수조건 점검을 별도로 눌러야 한다. 생성 버튼 근처에 남은 조건과 바로 가기를 보여줄 필요가 있다.
4. **첨부 형식 안내**: 참고자료 업로드에 허용 확장자 표시/파일 선택 제한, 한국어 오류 메시지가 필요하다.
5. **확인 범위 구분**: 작성 대상 확인, 원문 전체 확인, 제안서 요구사항, 증빙 확인의 차이를 명시해야 한다. 모두 저장한 뒤 상단이 다시 공고 핵심 확인을 안내하는 이유가 현재는 불명확하다.
