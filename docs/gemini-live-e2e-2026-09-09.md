## 테스트 중 보완

- Gemini 출력 상한을 Claude의 6,000과 분리하여 `GEMINI_MAX_OUTPUT_TOKENS`로 관리한다. 기본 16,384, 설정 범위 1,024~65,536이다. 실제 모델의 지원 한도는 별도로 확인해야 한다.
- Gemini 응답 대기를 180초로 조정했다. 자동 재시도는 하지 않는다.
- `MAX_TOKENS`는 `llm_output_limit`, 제한된 응답은 `llm_response_blocked`로 분류한다.
- 향후 일반 공급자 오류에는 비밀값 없는 HTTP 상태 숫자를 남긴다. 이미 종료된 2개 작업의 오류 이력은 소급 변경하지 않았다.
- 설정 등록만으로 표시되던 '실연동 데모 준비 완료'를 '기본 설정·접속 확인 · 실작업 검증 별도'로 수정했다. G2B 키·Qdrant 주소·템플릿 매핑 등록을 실제 호출 성공과 구분했다.
- 기존 workspace 테스트가 로컬의 실제 Gemini 키로 호출하지 않도록 테스트 공급자와 키를 격리했다.

보완 후 자동 검증: Gemini/호출 한도/원문 사전조건 68건, v2 회귀 34건, 설정 화면 4건 통과. 프론트 타입 및 변경 Python 파일 Ruff 검사 통과. Worker/API/감독 프로세스의 검사 대상 로그 4개에서 현재 키 문자열이 발견되지 않았다.
