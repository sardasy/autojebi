# 공고 핵심 사항 화면

- 공고 서류 검토의 기본 화면을 제출서류와 주요 사항(제출 일정, 계약/수행 기간, 예산, 참가자격, 평가 기준, 제출 방법)으로 변경했다.
- `notice_source` 본문의 규칙 기반 발췌만 사용한다. AI 후보 문장, 회사 참고자료, 파일 이름만으로 작성한 요구사항은 표시 근거로 사용하지 않는다.
- 법인/개인 등 조건, 수량과 부정 표현을 유지한다. 각 행에서 출처 파일을 다운로드할 수 있다. 발췌 목록은 전체 제출서류 확보/준비 완료 판정이 아니다.
- 이름이 같은 HWP/PDF 표시 중복은 제어문자가 적은 본문을 우선한다. 이름이 다른 파일의 기간 조건은 임의로 합치지 않고 병기한다. 원본 데이터는 수정하지 않는다.
- 규칙으로 식별되지 않은 항목은 원문 확인 필요로 표시한다. 임의 서식에 대한 완전한 추출을 보장하지 않으며 원문/상세 검토를 유지한다.
- AI 인용 오류/후보 채택 UI는 기본 화면에서 숨기고 `분석·작업 이력`에 보존했다. 실패 상태나 승인 정책을 변경하지 않는다.
- 현재 R26BK01722905-000의 공고 원문과 제안요청서에서 서로 다른 기간 표현을 발견하여 둘 다 표시한다. 어느 것이 우선하는지 자동 판단하지 않는다.
- 추가 유료 호출, 자동 채택, 회사 증빙 승인, 제출 동작 없음. 백엔드/API/DB 변경 없음.

검증: 프론트 전체 180개 통과, 규칙 보정 후 발췌 회귀 5개 재통과, 타입 검사 통과. mock E2E 5개 통과/기존 opt-in 2개 skip. 1280x800 및 390x800 캡처를 확인했고 가로 넘침 없음. 실제 공고 화면의 원문 발췌와 숨김 상태도 조회 확인했다.
